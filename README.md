# Secure AI Agent Access Control System

A web-based security project designed to control and monitor AI agent access to protected resources using permission policies and audit logging.

## Project Objectives

* Implement controlled access for AI agents.
* Apply permission checks before executing requested actions.
* Record access decisions for auditing and monitoring.
* Provide separate user and admin interfaces.
* Improve visibility into allowed and denied requests.

## Key Features

* User registration and login
* AI agent request submission
* Policy-based permission checking
* Access decision logging
* Admin dashboard for monitoring requests
* Customer data operations through controlled requests
